# Metrics and Experiments

## North-star hypothesis

The platform should optimize for:

> **Accepted useful work exchanged per active participant.**

Not raw task volume.

## Marketplace metrics

### Demand

- tasks created;
- tasks per builder;
- repeat builders;
- task completion rate.

### Supply

- active contributors;
- tasks claimed;
- repeat contributors;
- time to first task.

### Quality

- acceptance rate;
- first-pass acceptance;
- revision count;
- dispute rate.

### Liquidity

- median time to claim;
- percentage of tasks never claimed;
- percentage completed before deadline.

### Credit economy

- credits issued;
- credits earned;
- credits spent;
- credits locked;
- average balance;
- time from earning to spending.

## Experiment 1 — cash vs credits

Create two cohorts:

A. cash-equivalent reward  
B. ecosystem credits

Measure:

- claim rate;
- completion rate;
- return rate.

The purpose is to test whether credits have genuine motivational value.

## Experiment 2 — task size

Compare:

- 10–20 minute tasks;
- 30–60 minute tasks;
- 1–2 hour tasks.

Measure claim and acceptance rates.

## Experiment 3 — AI assistance

Ask contributors to report:

- manual time;
- AI time;
- total time;
- perceived difficulty;
- acceptance.

Measure whether AI materially increases useful throughput.

## Experiment 4 — credit sinks

Offer:

- expert review;
- tool trial;
- private beta;
- another task.

Observe what contributors choose.

## Experiment 5 — task packaging

Compare ordinary GitHub issues with structured task capsules.

Measure:

- clarification requests;
- claim rate;
- completion time;
- rejection rate.

## Critical dashboard

``` text
Tasks created             100
Tasks claimed              71
Tasks completed            58
Tasks accepted             49
First-pass accepted        38

Median time to claim       3h
Median completion          42m
Median review              12m

Credits issued          4,200
Credits spent           2,900
Credits dormant         1,300
```

The final two numbers matter enormously.

If earned credits are never spent, the economy is not working.
