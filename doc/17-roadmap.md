# Roadmap

## Phase 0 — Research

Goal:

Determine whether the economic behavior exists.

Deliverables:

- interviews;
- competitor mapping;
- credit experiments;
- task-size experiments.

## Phase 1 — Concierge MVP

Capabilities:

- accounts;
- manual task board;
- GitHub links;
- manual credit ledger;
- task acceptance;
- basic reputation.

No automation.

## Phase 2 — GitHub-native MVP

Add:

- GitHub App;
- issue import;
- task capsules;
- branch/PR workflow;
- automated status checks;
- credit ledger;
- reviews.

## Phase 3 — Marketplace intelligence

Add:

- contributor matching;
- task pricing recommendations;
- task difficulty estimation;
- contributor skill profiles;
- fraud detection.

## Phase 4 — MCP

Add:

- local MCP;
- task discovery;
- task claiming;
- scoped context;
- submission.

The contributor continues to control the local agent.

## Phase 5 — Secure private projects

Add:

- private repository support;
- context minimization;
- isolated workspaces;
- secret scanning;
- stronger identity verification.

## Phase 6 — Hosted execution

Only if demand exists:

- disposable containers;
- agent execution;
- usage limits;
- provider-neutral agent adapters.

## Phase 7 — Enterprise

Add:

- SSO;
- audit logs;
- organization policies;
- contributor allowlists;
- compliance features;
- private task networks.

## Phase 8 — Ecosystem

Potentially add:

- partner rewards;
- developer tool marketplace;
- compute;
- expert sessions;
- premium access.

## What should never be rushed

Do not rush:

- private code access;
- autonomous execution;
- cash conversion;
- account sharing;
- enterprise compliance.

The sequence should follow demonstrated demand rather than technical
excitement.
