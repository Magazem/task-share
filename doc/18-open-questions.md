# Open Questions

## Economic

1.  Will developers perform useful work for credits instead of cash?
2.  What makes credits valuable enough to retain?
3.  Which credit sinks matter most?
4.  How should credits be issued initially?
5.  Can the system avoid inflation?
6.  Should credits expire?
7.  Should credits be transferable between users?
8.  Should organizations be allowed to buy credits?

## Marketplace

9.  What task size has the best liquidity?
10. Which developer category should launch first?
11. How much task context is necessary?
12. What percentage of tasks require clarification?
13. How much review effort is acceptable?
14. What happens when a task has no takers?

## Trust

15. How much GitHub history is enough for verification?
16. How should reputation transfer between skills?
17. How should disputes be arbitrated?
18. How much should contributors stake?
19. How do we prevent collusion?

## Security

20. Can task capsules safely expose private code?
21. How do we detect secret leakage?
22. What sandbox is appropriate for hosted agents?
23. How much network access should an agent have?
24. Can we reliably detect malicious patches?

## AI

25. Does AI increase contributor throughput enough to matter?
26. Do contributors prefer Codex, Claude Code, Cursor, or manual work?
27. What should the MCP expose?
28. Should agents be allowed to claim tasks automatically?
29. How do we prevent autonomous agents from farming credits?

## Legal

30. Are closed-loop credits legally straightforward in target
    jurisdictions?
31. When does the model become a labor marketplace?
32. What IP terms are needed?
33. What provider restrictions apply to each supported agent?
34. What liability arises from contributor code?

## Strategic

35. Could GitHub build this?
36. Could existing bounty platforms add credits?
37. Could agent marketplaces move toward human contributors?
38. Is the strongest business actually the trust/security layer?
39. Is the credit economy the product or merely an onboarding mechanism?
40. What happens if cash ultimately proves much more attractive?

## The most important unresolved question

> **If a developer has an hour of free time and a capable coding agent,
> will they choose to spend that hour completing someone else’s task for
> ecosystem credits?**

Everything else should be built around learning the answer.
